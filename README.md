## Proximity Alarm 
**Built with the following components:**
1) Arduino Uno R3 - processes instructions.
2) Ultrasonic Sensor (HC-SR04)- detects the time in micro seconds from which distance is calculated.
3) LED bulb and buzzer- used for signal purpose when the object is within the threshold.

**Thought process ,Workflow and Connections**:

First, I connected the 4 pins of ultrasonic sensor namely:
1) Vcc- Power source pin connected to the constant 5v power supply.
2) Trigger- Used as output pin to generate pulse by using digitalWrite() and switching it from LOW-HIGH-LOW this generates a pulse and it is connected to the digital pin 12.
3) Echo - Used as input pin which detects the pulse generated by the trigger pin and from this the total time taken by the pulse
to travel from the trigger pin to object and finally to the echo pin (in microseconds) can be calculated by reading the input and it is connected to the digital pin 13.
4) Gnd- Connected to the GND pin in the arduino(Ground) to complete the circuit.

So now I have the ultrasonic sensor ready, after this I setup the two components used as a signal when the object is within the 
threshold distance:
1) LED - The longer leg of the LED is connected to the resistor which in turn is connected to the digital pin 8 so that we can control it using digitalWrite() and the short leg of the LED is connected to the ground pin in the arduino.
2) Buzzer- The positive end of the buzzer is connected to the digital pin 7 so that we can control it using digitalWrite() and the negative end is connected to the ground pin in the arduino.

Now I have all the components ready , now moving on to the code part:
First I setup all the pinModes inside the setup() as INPUTS and OUTPUTS where we have the triggerPin, LedPin and the buzzerPin as OUTPUT and the echoPin as Input. I also start the Serial monitor which is later used in the loop() to print the distance values to keep track of.

Then inside the loop() first I generate the pulse from the trigger pin by using digitalWrite() by setting it LOW waiting from 10 microseconds then setting it HIGH again waiting for 10 microseconds and then again setting it LOW by this means we generate a pulse from the trigger pin.

This pulse is then detected by the echoPin and thus we get the time in microseconds by using the pulseIn().

Now this gives only time but we want distance for this I used the formula distance=rate*time where we want distance in inches , we have rate in miles/hour and time in microseconds.

Now our task is to do dimensional analysis so that units of right side matches with the left side.

So in RHS we have  (miles/hour) * microseconds , if we convert this into (inches/microseconds) * microseconds then it matches with the LHS. We know the speed of sound is ~ 765 miles/hour, so we use the unitrary method which goes like:
RHS= (765 mile/ hour)*(5280 feet/1 mile)*(12 inches/1feet)*(1 hour/3600 seconds)*(1 second/10^6 microsecond)
So essentially distance in (inches)= [(765 * 5280 * 12)/(3600 * 10^6)] * (time input in microseconds).

So now using the above relation we get our distance in inches from our time input in microseconds.

After this depending on the distance range in my case if it is between 30 inches and 10 inches the LED and buzzer will switch on wait for 5 seconds and switch off and wait for 5 seconds, or if it is between 10 inches and 5 inches the LED and buzzer will switch on wait for 3 seconds and switch off and wait for 3 seconds, or if it is less than 5 inches they switch on wait for 1 second and switch off wait for 1 second and it keeps looping on.
